Política de privacidad

Respaldo en preparación. La conexión y las copias automáticas todavía deben verificarse. Estas páginas describen la función prevista; no confirman que esté operativa.

Responsable y alcance

Jonatan Spinoza es responsable de Respaldo de mis apps. Contacto: jonaymeli42@gmail.com. Esta política describe el tratamiento previsto para el respaldo personal de Control de préstamos y Control de Tarjetas.

Datos locales y copias

Los datos de trabajo de las apps se almacenan localmente en el navegador del dispositivo. Al habilitar el respaldo, se enviarán copias JSON de los datos de la app mediante el servicio de Cloudflare a la carpeta appDataFolder de la cuenta de Google autorizada. El JSON puede contener información personal y financiera que el usuario haya registrado.

Se utilizará el correo verificado por Google para comprobar que la conexión corresponde a la cuenta autorizada. El permiso previsto para Drive se limita a los datos de esta aplicación en appDataFolder; no concede acceso general a los archivos de Drive.

Conexión y tratamiento técnico

La arquitectura prevista guarda los tokens de conexión cifrados en Cloudflare KV y la sesión del dispositivo en el navegador. El código desplegado y su funcionamiento aún deben revisarse para verificar esta implementación.

El JSON de respaldo no tendrá cifrado adicional de su contenido por parte de este servicio. El cifrado previsto de los tokens no equivale a cifrar el contenido de las copias. No se afirma seguridad absoluta ni otras protecciones que no se hayan comprobado.

GitHub aloja el código y las páginas públicas. Los respaldos privados no se publicarán en GitHub ni en GitHub Pages. Google y Cloudflare procesarán los datos necesarios para la autorización, la transferencia y el almacenamiento de las copias y de la conexión.

Finalidad y política de Google

Los datos se utilizarán únicamente para autorizar la cuenta, crear copias, consultar las copias y permitir su descarga. No se venderán ni se utilizarán para publicidad o entrenamiento de inteligencia artificial.

El uso y la transferencia de información recibida de las API de Google se ajustarán a la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de Uso Limitado (Limited Use). Esta declaración expresa el compromiso del servicio; el funcionamiento del respaldo continúa pendiente de verificación.

Conservación y desconexión

Cada copia nueva se guardará sin sobrescribir ni borrar automáticamente las anteriores. Las copias podrán ocupar espacio y estarán sujetas a los límites de Google.

Desconectar un dispositivo finalizará su conexión con el servicio, pero no eliminará las copias guardadas ni revocará las conexiones de otros dispositivos. Para retirar el permiso de Google debe utilizarse la gestión de conexiones de la cuenta.

Cómo retirar el permiso y eliminar los datos ocultos

  1. Para retirar el permiso, abrí las conexiones con aplicaciones de tu cuenta de Google, buscá Respaldo de mis apps y elegí la opción de eliminar la conexión o el acceso. Esto puede afectar las conexiones de esa cuenta en todos los dispositivos; no elimina por sí solo las copias guardadas.
  2. Para eliminar los datos de appDataFolder, abrí Google Drive, entrá en Configuración → Administrar aplicaciones, buscá Respaldo de mis apps y, en Opciones, elegí Eliminar datos ocultos de la aplicación, si aparece. En el celular puede ser necesario activar “Sitio de escritorio” en el navegador. Los nombres de las opciones pueden variar. Esta acción elimina los datos ocultos guardados por esta aplicación; descargá antes las copias que quieras conservar.
  3. Las copias locales del navegador y los archivos que hayas descargado se gestionan por separado. Borrar datos del navegador puede eliminar los datos locales de las apps; conservá primero una copia manual.

Para consultas sobre privacidad o la conexión almacenada por el servicio, escribí al responsable. No envíes contraseñas, tokens ni secretos por correo.
