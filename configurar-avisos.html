Avisos de cobros a las 9:00

Se configura una vez. Después, el celular puede recibir los avisos aunque la app esté cerrada.

1. Crear el servicio

En Cloudflare, abrí Workers & Pages → Create application → Create Worker / Hello World. Usá el nombre avisos-prestamos y publicalo.

Es un Worker nuevo. Conservá el servicio de respaldos tal como está.

2. Copiar el código

En el Worker nuevo, abrí Edit code, reemplazá el código por el que copia este botón y tocá Deploy.

Abrir el archivo de código

3. Crear y vincular el almacenamiento

En Storage & Databases → KV, creá un espacio llamado avisos-prestamos.

Volvé al Worker avisos-prestamos. En Bindings → Add binding → KV namespace, usá AVISOS como nombre de variable y seleccioná el espacio que acabás de crear. Guardá y publicá si Cloudflare lo solicita.

4. Programar la mañana

En Settings → Trigger Events → Cron Triggers, agregá esta expresión:

*/5 12 * * *

Cloudflare usa UTC. Empieza a las 9:00 de Argentina y reintenta cada cinco minutos hasta las 9:55 si falla la entrega. El mismo cobro diario se marca para no enviarlo de nuevo cuando el servicio confirma el envío.

5. Comprobar y activar en el celular

En la app, entrá en Respaldo / Más → Avisos de mañana. Conectá Google en Respaldo si todavía no está conectado. Tocá Activar avisos de mañana, permití las notificaciones y después Enviar aviso de prueba.

Abrir Avisos de mañana

El servicio recibe fechas, cantidades e importes de los cobros pendientes, sin nombres de clientes. Actualizá los préstamos con Internet para mantener los avisos al día. Solo avisa si hay cobros pendientes que vencen ese día. Si el celular está sin conexión, la entrega puede demorarse; cada aviso vence a los 30 minutos para evitar entregas muy tardías.
